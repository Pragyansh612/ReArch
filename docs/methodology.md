# Methodology

How every number in ReArch is produced, in plain English. Updated after each phase.

## Phase 0 — Setup
No numbers are produced yet. `config/assumptions.yaml` holds placeholder rates that will be
justified in Phase 3. Target-selection figures in `docs/target.md` were counted directly from the
cloned repositories (file counts, line counts, `@Test` occurrences), with no estimation.
